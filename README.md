## Лабораторная работа 4

1. На странице "Contact me" *FlexBox* используется для:
 - Построения двух колонок (левая и правая части) внутри .container.
 - Организации вертикального и горизонтального распределения контента в .right-side, nav и .social-icons.
 2. Вёрстка с использованием Grid применена: 
 - Для элементов с классом .project на странице "Portfolio"
 - для карточек с навыками на странице "About me"

 ![Alt Text](https://avatars.mds.yandex.net/i?id=99373a4c31f18d943aa2edbb461a23b9_l-5016868-images-thumbs&n=13)
 
3. Все цвета задаются только с помощью переменных в CSS
4. Реализация анимации (красивой!) с помощью CSS:
- Появление формы на странице "Registration"
- Переливание цвета радугой на странице "About me"
5. Реализация страницы с формой регистрации, включающей не менее 3 различных типов полей.
6. Создание класса, содержащего конструктор и метод форматированного вывода на консоль. При нажатии на кнопку отправки данных на сервер должен создаваться объект, хранящий введённые данные, после чего вызывается метод вывода на консоль.

## Лабораторная работа 5

1. Динамическая проверка данных формы в процессе ввода с использованием событийной модели JavaScript и вывод текстовых подсказок для пользователя.
2. Реализация отправки данных формы после её валидации на сервер через POST-запрос (без обработки на серверной стороне).
3. Реализация асинхронного запроса на сервер для получения данных (например, для заполнения одной из таблиц) с обязательной обработкой возможных ошибок.
4. Организация асинхронного получения данных таким образом, чтобы оно выполнялось периодически (например, раз в 5 минут).

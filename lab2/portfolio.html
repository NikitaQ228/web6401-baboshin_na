Learn & Play

The Learn&Play project is a service for preparing for the Basic State Exam with elements of gamification. It is designed to motivate students in grades 8-9 to diligently study the educational material and successfully pass the exam.

My contribution to the project included:

  • Developed backend APIs using Spring Boot, utilizing Hibernate for seamless database interaction.
  • Implemented foundational authentication and authorization mechanisms with Spring Security.
  • Conducted thorough API testing and debugging using Postman.
  • Collaborated within a team environment employing Git for version control and YouTrack for task tracking and workflow coordination.
  • Authored complex server-side queries to optimize data handling and retrieval.

Avoided Connections

Avoided Connections is an anti-social network that reverses the usual "looking for you" concept. Instead of people seeking those who smiled or caught their eye, it lets users share stories about people they quickly avoided in public places, like beggars, scammers, or drunken individuals, capturing their eccentric public behaviors.

My new skills:

  • Configured JWT-based authentication for secure user access
  • Developed frontend part of the project using modern frameworks
  • Used Docker to containerize backend, database, and frontend services
